# ESTÉRUM — главный экран

Первый экран интернет-магазина ароматических свечей ESTÉRUM: hero «Атмосфера в деталях»
и галерея коллекции «Четыре состояния».

Вёрстка перенесена из макета Figma «ESTERUM — Главный экран» (Desktop — 1440 × 900,
Mobile — 391). Без сборки и зависимостей: откройте `index.html` в браузере.

## Как устроено

Десктопная раскладка построена на одном модуле:

```css
--u: min(calc(100vw / 1440), calc(100vh / 900));
```

`1u` — один пиксель макета, масштаб берётся по той стороне, которой не хватает.
Поэтому экран всегда помещается в окно целиком, а пропорции отступов, кеглей и кадров
остаются макетными. Поля страницы — фиксированные 60 px, колонки тянутся в пропорции
604 : 708. Ниже 900 px по ширине включается отдельная мобильная раскладка.

## Анимация

- появление первого экрана: заголовок выезжает по строкам из-под маски, линейка
  надколонника прочерчивается, кадр открывается шторкой, превью подъезжают справа;
- галерея: перекрёстное растворение кадров, подпись меняется сдвигом, автолистание
  раз в 6 с с паузой на наведении, фокусе и неактивной вкладке, стрелки ← →;
- микровзаимодействия: подчёркивания в меню, заливка кнопки, приближение превью,
  раскрытие категорий, расширение поля поиска;
- всё отключается при `prefers-reduced-motion: reduce`.
